# User Accounts Page Overrides

## Layout

- 顶部为标题、主动作与导入/导出；下一行是可折叠筛选区，筛选值、页码和排序写入 URL。
- 1200px 及以上为部门树筛选 + 用户表格；更窄视口隐藏部门树并保留顶部筛选和表格内部横向滚动，避免页面级溢出；小于 768px 时表格收敛为含状态的用户主列和动作菜单。
- 选择行后出现批量操作栏，始终显示已选数量；切换筛选时清理不可见选择并公告变化。

## Table and actions

- 主列为显示名/账号，附状态、部门、岗位、角色、最后登录；不展示密码 Hash、Token、MFA Secret 或未脱敏凭据。
- 行动作与批量动作按 `iam.user.*`/`org.assignment.update` 分别控制；隐藏按钮不替代 API 授权。
- 启停、解锁、重置密码与批量操作显示影响数量、会话撤销/强制改密后果和可取消确认。
- 创建/编辑使用 Drawer + RHF/Zod；完整详情使用隐藏路由。

## Import/export

- 导入先校验文件类型/大小并显示逐行结果摘要；第三方对象存储不可用时使用本地受限上传 Adapter。
- 导出使用当前服务端筛选生成，不把未授权字段带到客户端；写/导出请求不自动重放。

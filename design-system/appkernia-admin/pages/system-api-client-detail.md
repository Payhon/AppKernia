# API Client Detail Override

- Preserve App Shell and highlight API Clients for this hidden detail route.
- Show tenant-scoped identity metadata, CIDRs, stable permission codes, and secret metadata only.
- Plaintext client secrets, secret hashes, bearer tokens, and authorization headers must never be returned, persisted, or rendered.
- Provide loading, not-found/error retry, safe list navigation, localized timestamps, and responsive stacked descriptions.

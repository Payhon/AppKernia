# Access Roles Page Overrides

## Layout

- 列表顶部放关键词、状态和角色类型筛选，状态写入 URL；完整配置进入可深链的隐藏详情路由。
- 详情使用基本信息、权限、菜单、数据范围、成员标签；当前标签写入 URL，刷新与浏览器返回可恢复。
- 权限与菜单分别使用独立树/分组选择器，并明确显示已选数量，禁止用菜单勾选暗示后端权限。

## Actions

- 新建和轻量编辑使用 Drawer + RHF/Zod；系统角色不可删除等边界从服务端返回并在 UI 解释。
- 替换权限、菜单和数据范围前展示影响摘要；提交期间禁用重复操作，写请求不自动重放。
- custom 数据范围只允许选择当前租户组织单元，其他 scope 清空 custom unit ids。

# 隐私与系统权限矩阵

机器事实源：`spec/privacy-capability-matrix.json`。

## 原则

- 首次启动随包携带可离线阅读的隐私政策与用户协议快照。
- 用户同意当前版本前，不初始化 Push、统计、OAuth SDK 或其他第三方 SDK。
- 系统权限只在用户触发对应功能时申请，说明用途并提供拒绝后的降级路径。
- Core 默认不使用定位、通讯录、麦克风、广告标识，也不自动读取剪贴板。
- 头像优先使用系统 Picker；不为“方便”申请整个媒体库或广泛文件权限。
- Privacy manifest/权限文案必须与真实代码调用一致，未使用的权限必须删除。

## Agent 验收

每个新增平台能力必须同步：Feature Flag、隐私文档、manifest/权限声明、三端拒绝/允许测试、数据保留说明和安全审查。未登记能力不得进入 Core。

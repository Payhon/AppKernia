# Built-in H5 design system

公众号式阅读页面和 Apple-inspired 发行页共享系统字体、AppKernia 蓝色、语义化浅深色 Token。禁止外部字体、伪造评分、重阴影和运行时任意 CSS/JS。

- 阅读栏最大 680px，17px 正文，1.8 行高，移动端 20px 留白，24–28px 标题；图片、表格、代码不撑宽页面。
- 图文资讯使用媒体优先的滑动图集、位置计数和可键盘操作的缩略图；视频不自动播放，并通过播放器右上角的两个 44px SVG 图标在 16:9 宽屏详情与 9:16 沉浸舞台之间切换。
- 页面语言切换是顶部 Header 的 44px 地球图标，使用可访问名称和原生 Tooltip；底部不重复语言入口。资讯与单页的下载推广由后台双语配置和显示开关控制。
- 下载页最大 1040px，真实图标/截图、分组背景、明确主操作、44px 点击目标，safe-area 安全留白。
- 默认完整 HTML 和普通链接，无 JS 仍可操作。自动识别只推荐，手动选择优先，不自动跳转。
- zh-CN/en-US，浅深色，375/768/1440px，200% 字体，键盘与 reduced-motion 均需验收。

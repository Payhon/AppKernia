# Article / document override

正文为白底单栏阅读，不使用卡片 Hero。标题、来源、日期在正文前；下载 CTA 放文末，不固定遮挡内容。保留段落、标题、引用、列表、代码、表格和图片说明层级。法律页面显示版本，不记录同意。

图文类型在标题前展示 4:5 媒体舞台，使用 CSS Scroll Snap、计数、前后按钮与缩略图；无脚本仍可横向浏览全部图片。视频类型默认 16:9 宽屏播放器，播放器右上角浮动宽屏/沉浸 SVG 图标组；选中状态同时使用底色与 `aria-pressed`，图标有双语可访问名称。沉浸模式使用受视口约束的 9:16 黑色舞台与底部信息渐变，不伪造点赞、评论或播放量。视频必须由用户点击播放，切换布局时暂停。

下载推广只在发行页已公开且后台推广开关开启时显示。后台可配置每种语言的标题、说明和按钮文字；空值使用内置安全回退。关闭推广时，Header 下载入口和正文后的推广同时隐藏，公开下载页本身不下架。

# Decisions

- 图文使用真实媒体数组，不把封面重复成图集内容；4:5 黑色媒体舞台允许不同宽高比图片完整显示。
- 使用原生 CSS Scroll Snap 与小型自托管脚本维护计数、缩略图和键盘按钮；无脚本时轨道仍可滚动。
- 视频使用原生 `video controls playsinline preload=metadata`，不自动播放。宽屏是 16:9 详情模式，沉浸模式是受视口约束的 9:16 舞台；切换时暂停播放。
- 不复制小红书、YouTube 或抖音的品牌、图标、互动数字和导航，只采用用户明确要求的内容呈现模式。
- 外部视频 URL 继续由业务白名单校验，H5 渲染边界再限制为 HTTPS，并把精确来源写入 CSP `media-src`。

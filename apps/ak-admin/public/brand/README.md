```text
Asset type: AppKernia web admin primary brand mark
Input images: Image 1 is a visual reference only for brand direction, not an edit target and not for exact copying.
Primary request: Create an original, production-polished AppKernia symbol that combines a geometric uppercase A / mountain-like portal with one clean rising orbital stroke suggesting acceleration, intelligence, and cross-platform flow.
Style/medium: minimal vector-friendly logo mark rendered as crisp flat artwork; strong silhouette; no mockup; no 3D extrusion.
Composition/framing: one centered square icon mark with generous even padding; rounded-square outer container; simple internal geometry readable at 24px.
Color palette: luminous electric blue to cyan to emerald with a restrained lime highlight, inspired by Image 1; no purple, pink, orange, red, black, or gray inside the subject.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for local background removal.
Text: none.
Constraints: original design; preserve the broad A-plus-upward-motion idea but use distinct geometry from the reference; uniform chroma background; crisp edges; no shadow, reflection, watermark, or extra symbols.
```

The flat chroma background was removed with the installed imagegen helper. A hard matte plus one-pixel edge contraction was selected because the soft-matte pass incorrectly reduced the opacity of the internal white geometry.

# Request

Admin 内容工作台：文章/图文/视频、分类、专题、标签、评论与举报审核；文章编辑 Drawer 拆分 Meta/内容 Tab，双语 Markdown 编辑、资源选择器预览、媒体/视频预览、发布校验、筛选分页、批量审核、权限边界和 375/768/1440 响应式。

测试反馈修正：补齐文件选择器类型筛选与预览区域的 `zh-CN`/`en-US` 文案；将视频来源和视频外链移动到内容 Tab；编辑既有图文时主动加载 1–9 张媒体缩略图，而不是仅显示标题。

Meta 排版反馈修正：封面选择/预览与评论、置顶、精选、最新开关拆分为两个视觉行；未选中开关也必须显示字段名和本地化状态文字。

文件选择器反馈修正：左侧文件表格需要直接显示可辨识图片内容的小缩略图，文件名降为次级信息并放在缩略图下方。

文件选择器密度与筛选反馈修正：进一步压缩列表行高和缩略图尺寸；增加上传时间、文件大小列；在顶部搜索旁增加上传开始/结束日期约束，并对完整服务端列表生效。

文件选择器 footer 反馈修正：将“上传文件”按钮及其存储/大小提示移动到对话框左下角，与右侧“取消、选择”按钮处于同一 footer 行。

文件选择器行选择反馈修正：点击文件列表任意一列都应选择该行，而不是只能点击最左侧的单选控件。

文件选择器选中态反馈修正：选中行背景需要变浅并保持所有文字清晰可读；footer 左侧“上传文件”按钮增加一致的上传图标。

文件选择器窗口反馈修正：文件列表和预览之间增加可拖动宽度分割并设置双方最小宽度；预览支持关闭和重新展开；Modal 支持最大化/还原、拖动移动和右下角缩放，优先复用现有组件扩展点。

文件选择器多视图反馈修正：预览折叠后的入口改为右侧垂直居中的小型左箭头；筛选行增加图标下拉，可切换网格、约 24px 紧凑表格和当前缩略图视图；已选提示改为浅灰底深灰字；最大化和关闭组成垂直对齐的统一按钮组。

文件选择器窗口与全局下拉反馈修正：取消左侧文件表头右上圆角；全局 Select/Dropdown 选中项使用浅色背景和深色文字；移除右下角十字图标，将缩放抽为共享 `AkModal.resizable` 能力，右下角仅在 hover/focus/拖动时显示内侧圆角弧线并支持真实拖拽改尺寸。

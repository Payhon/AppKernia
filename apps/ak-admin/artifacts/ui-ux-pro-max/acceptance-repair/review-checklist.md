# Review checklist

- [x] Reserved pages with zero translations render without an exception.
- [x] `zh-CN` and `en-US` display meaningful localized fallbacks.
- [x] Application `active` and `disabled` statuses are localized.
- [x] No user-visible hard-coded Chinese or English is introduced in JSX.
- [x] Keyboard/focus and responsive table behavior are unchanged.
- [x] Unit/component tests, lint, typecheck, build, bilingual browser checks and screenshots pass.

# Design decisions

1. 行操作保持原顺序，只把“分享配置”更名为“客户端配置”；任一已注册 Tab 具备读取权限时入口可见。
2. 约 760 px Modal 承载代码注册的 Tabs；窄屏使用全屏宽度。没有全局保存按钮，每个 Tab 管理自己的请求和反馈。
3. Tab 内容始终挂载，切换不丢失未提交状态；关闭时聚合各 Tab 的 dirty 状态并确认。
4. 分享绑定功能抽取为独立 Tab，原接口、预检和安全规则保持不变。
5. 扫码域名使用可增删行和行内错误；关闭 WebView 时保留列表，成功保存后采用服务端返回的新锁版本。
6. `read` 控制查看，`update` 控制编辑/保存/解绑；前端裁剪不替代后端授权。

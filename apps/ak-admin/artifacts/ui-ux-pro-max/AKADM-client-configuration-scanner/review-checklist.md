# Review checklist

- [x] 客户端配置入口与任一 Tab 读取权限组合已覆盖行为测试。
- [x] Tab 顺序由 `ClientConfigTabDefinition` 注册表固定，后续能力可追加注册。
- [x] 分享和扫码 Tab 独立加载、校验、保存，不存在全局保存按钮。
- [x] Tab 切换保留内容，关闭 dirty Modal 前确认。
- [x] 扫码规则支持逐行错误、冲突刷新、只读权限和双语文案。
- [x] Modal/Tabs 复用 Ant Design 键盘、焦点陷阱和错误语义。
- [ ] 1440 × 900 中英文浅色/深色截图。
- [ ] 768 px 与 375 × 812 响应式截图。
- [ ] 浏览器键盘、读屏、焦点恢复与冲突交互人工验收。

未执行项在取得真实截图或交互证据前保持未勾选。

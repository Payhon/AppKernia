# UI Skill output

The repository-local `ui-ux-pro-max` search was run for:

- a master AppKernia Admin system;
- a high-density system settings page;
- a file storage/upload page;
- React form, accessibility, upload progress, and responsive administration patterns.

Useful recommendations retained: strong focus visibility, semantic labels for icon actions, progress feedback, 12-column/high-density composition, responsive stacking, and no color-only status.

Recommendations rejected as incompatible with the product: pharmacy/marketing classification, dark-tech palette, green CTA, remote Lexend/Source Sans fonts, hero/contact-sales page structure, animated dashboards, and layout-shifting hover transforms.

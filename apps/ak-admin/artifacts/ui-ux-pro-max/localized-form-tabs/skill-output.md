Skill 推荐 Minimalism / Swiss Style，同时给出通用靛青与绿色配色、Inter 网络字体。专项 UX 结果强调：

- 表单错误需要通过 `role=alert` 或同等语义通知，不能只有颜色。
- 所有 Tab 和字段必须支持键盘访问并保留可见焦点。
- 错误应靠近对应字段，提交操作需要明确 loading/success/error 反馈。
- 避免用 `overflow: hidden` 裁掉重要内容，窄屏应在局部导航中处理溢出。
- React 表单使用受控状态；关联的 Tab 与 TabPanel 共享状态。

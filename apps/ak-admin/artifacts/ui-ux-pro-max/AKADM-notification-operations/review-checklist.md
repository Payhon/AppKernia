# Review checklist

- [ ] `zh-CN` and `en-US` keys and placeholders match.
- [ ] View and retry permissions are enforced independently.
- [ ] Loading, empty, error, 403 and refreshing states are visible.
- [ ] Filters and active tab restore from URL search parameters.
- [ ] Status never relies on color alone.
- [ ] Charts have a table alternative and accessible label.
- [ ] Retry dialogs trap focus and restore it on close.
- [ ] 1440 light/dark, 768 and 375 layouts have no page overflow.
- [ ] Screenshots and axe results are captured after implementation.

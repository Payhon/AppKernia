# App public web configuration

在 App 管理行操作打开独立 Drawer，不覆盖其他 App 配置。沿用 Admin Master、RHF/Zod、双语标签和权限控制。显示发布开关、APK 开关、推广显示开关、双语名称/介绍/推广标题/说明/按钮文字、已有市场的平台与 HTTPS 地址、公开链接和二维码。推广文案允许留空并使用 H5 内置回退；开关关闭后只隐藏文章及单页的推广，不下架发行页。配置缺失、保存错误和版本冲突有明确状态；只预览已发布内容。

## 手机预览

使用共享 AkModal，工具栏位于手机外壳上方，显示页面标题及刷新/复制/关闭 SVG 图标和双语 Tooltip。393×852 逻辑屏幕、黑色圆角外壳、灵动岛、侧键及底部 Home Indicator 仅做尺寸与外观模拟；装饰不可覆盖 iframe，toolbar 触控目标至少 44px。仅手机等比缩放，不缩放工具栏。沿用 Admin 固定浅色主题，H5 继续跟随系统配色。

打开时加载真实已发布页面，关闭卸载。使用受校验来源的消息确认就绪；超时可重试/独立打开，复制失败展示只读可选 URL。站内阅读留在 iframe，外部及 APK 链接在用户点击后另开页面。键盘可以离开 iframe、关闭 Modal 并返回触发控件。

资讯及单页的预览状态都由页面层持有，行内按钮仅触发预览；表格断点调整/单元格重建不得关闭已打开的预览。外层 Modal 使用遮罩可用空间约束，内部容器保持固定边界与 flex 布局，英文长标题和 200% CSS 缩放时仍须保持工具栏和手机可见。

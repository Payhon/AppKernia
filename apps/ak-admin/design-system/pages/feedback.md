# App feedback

Follow MASTER.md. Use the global App selector, a searchable paginated table with status/date filters, and a detail drawer. Contact information belongs in authorized detail, not list summaries. Render feedback and replies as plain text. Screenshot URLs are authenticated Blob previews, released on close/scope changes. Reply and status actions retain user input on failure and show a localized conflict notice on stale versions. Support 768px and both locales without page overflow.

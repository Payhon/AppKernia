# AKDOCS-006 ui-ux-pro-max output

## Required design-system query

Query:

`open source developer platform documentation landing page hero gradient product screenshot professional minimal`

Relevant recommendations:

- Documentation landing pattern with a clear primary CTA.
- Inter-style neutral typography for a minimal, professional developer surface.
- Sky-blue trust palette with WCAG AA contrast.
- Test responsive states at 375, 768, 1024, and 1440 px.

## Supplemental UX query

Query:

`hero gradient product screenshot responsive contrast accessibility`

Applied guidance:

- Maintain at least 4.5:1 normal-text contrast.
- Scale images through their container rather than fixed widths.
- Prevent page-level horizontal scrolling.
- Preserve descriptive image alternatives.

Rejected guidance:

- Testimonials, ratings, client logos, orange conversion CTA, and animated
  social-proof effects do not match the current open-source project stage.

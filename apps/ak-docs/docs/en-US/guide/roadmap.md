# Roadmap

AppKernia is moving toward its first stable Core release. The roadmap communicates direction, not guaranteed dates. A capability is complete only when code, contracts, tests, and relevant platform acceptance agree.

## Core 1.0

- Secure authentication, session and refresh-token rotation, account recovery
- Users, tenants, organizations, RBAC, and data scopes
- Admin menus, configuration, dictionaries, files, notifications, jobs, and audit
- Mobile login, profile, security, messages, settings, and three-platform adaptation
- Complete `zh-CN` and `en-US` contracts
- OpenAPI-generated clients and GitHub Actions quality gates

## Later directions

- Production MFA/OAuth adapters and more physical-platform evidence
- Webhooks, API clients, external notifications, and object storage ecosystem
- Optional billing without coupling it to core identity
- A richer component gallery, example domains, and versioned migration guides

For the most precise current state, read `docs/IMPLEMENTATION_STATUS.md` and `docs/CODEX_DELIVERY_REPORT.md` in the repository.

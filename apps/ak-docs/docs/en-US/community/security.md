# Security reporting

AppKernia has no stable release yet; security fixes currently target the latest default branch.

Use the repository's **Private vulnerability reporting / Security advisory** channel. Do not open a public issue or include real credentials or personal data in logs, screenshots, or reproduction repositories.

Include the affected version or commit, impact and prerequisites, minimal controlled reproduction, and a suggested mitigation when available. Do not disclose details until maintainers confirm and coordinate. See `SECURITY.md` in the repository for the complete policy.

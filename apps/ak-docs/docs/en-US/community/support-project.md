# Support AppKernia

Open-source projects need more than code. They need to be discovered, tried, and given thoughtful feedback.

If you believe Mobile + Admin + Server should be one coherent foundation, please [Star AppKernia on GitHub](https://github.com/Payhon/AppKernia). A Star helps developers searching for a cross-platform—and especially HarmonyOS-inclusive—path find the project. It also tells maintainers that the direction is worth sustained effort.

You can also write a reproducible issue, point out where the first-run guide failed, verify a platform you know, share the project without exaggerating unfinished features, review a pull request, or help another contributor clarify a problem.

The best support leaves the project a little more trustworthy than you found it.

# 安全报告

AppKernia 尚未发布稳定版本，安全修复当前面向默认分支的最新代码。

请使用 GitHub 仓库的 **Private vulnerability reporting / Security advisory** 私下报告。不要创建公开 Issue，也不要在日志、截图或复现仓库中放入真实凭据或个人数据。

报告建议包含：

- 受影响版本或 commit。
- 影响范围和攻击前提。
- 最小、可控的复现步骤。
- 建议修复或缓解方式（如有）。

在维护者确认和协调披露前，请勿公开漏洞细节。完整政策见仓库 `SECURITY.md`。

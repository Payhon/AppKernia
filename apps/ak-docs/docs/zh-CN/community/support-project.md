# 支持 AppKernia

开源项目最稀缺的不只是代码，也是持续被看见、被试用和被认真反馈。

## 留下一颗 Star

如果你认同“Mobile + Admin + Server 应该是一套完整基座”的方向，请在 [GitHub 为 AppKernia 点 Star](https://github.com/Payhon/AppKernia)。它不只是一个数字：Star 会帮助项目被更多正在寻找跨端、尤其是鸿蒙一体化方案的开发者发现，也让维护者知道这条路值得继续投入。

## 还有这些方式

- 把真实使用中的问题写成可复现 Issue。
- 告诉我们哪一段向导让第一次运行卡住了。
- 在你熟悉的平台完成一次构建或真机验证。
- 向团队或社区分享项目，但请不要夸大尚未完成的能力。
- Review 一个 PR，或帮助另一位贡献者把问题说清楚。

最好的支持，是让项目比你遇见它时更可信一点。

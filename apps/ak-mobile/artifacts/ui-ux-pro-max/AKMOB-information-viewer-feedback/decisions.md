# Decisions

- 移除 `ak-video-viewer` 对 `uni.getVideoInfo` 的直接调用。原因是该 API 由可选 `uni-media` 原生模块提供，编译期存在不等于测试自定义基座包含对应 Swift/Kotlin 类。
- 默认方向以视频封面的自然宽高作为无额外原生模块的安全提示：高大于宽时默认竖屏，否则默认横屏；无封面或加载失败时稳定回退横屏。用户手动切换后不再被异步封面加载覆盖。
- 竖屏模式给舞台和播放器绑定直接 class，避免 UVue 对后代选择器支持差异导致高度规则未生效。舞台全屏并 `justify-content: center`；播放器高度按封面宽高比和当前窗口宽度计算并限制在可视高度内。
- 竖屏播放器使用 `contain`，保证横向视频切到竖屏时完整画面垂直居中，不强制放大裁切；横屏播放器继续使用 `cover`。
- 图集点击调用平台 `uni.previewImage`，把按展示顺序解析后的 URL 数组一次传入，交由原生全屏预览提供缩放和左右切换。
- 继续保留 44×44 图标按钮、安全区和不自动播放约束。

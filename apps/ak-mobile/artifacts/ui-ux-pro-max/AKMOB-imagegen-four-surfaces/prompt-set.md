# Final ImageGen prompt set
All four prompts used the `ui-mockup` taxonomy and requested a single edge-to-edge portrait product screen, not a device marketing mockup.

## Shared visual constraints

- High-fidelity production mobile UI; Minimal Swiss-inspired.
- Light mode, `#F8FAFC` page, white cards, `#2563EB` accent, `#0F172A` primary text, `#475569` secondary text, `#E2E8F0` borders.
- Platform system sans-serif, 16 px card radius, restrained shadow, consistent outline icons, 44 px minimum targets, safe-area spacing.
- Simplified Chinese, no emoji, third-party marks, watermark, phone frame, glassmorphism, neon, or dark mode.

## Home

- Header `AppKernia`, greeting `早上好，Alex`, restrained blue hero, four quick actions, two featured articles.
- Exact three-tab navigation `首页 / 消息 / 我的`, Home active.

## Profile

- The generated Home screen was used as the visual reference.
- Identity card for fictional `Alex Chen`, grouped self-service and settings rows, separate red outlined logout action.
- Exact three-tab navigation retained, Profile active.

## Article list

- The generated Profile screen was used as the visual reference.
- Pushed page with back action, `文章` title, `搜索文章`, four category chips, and three vertically stacked article cards.
- No bottom TabBar or desktop pagination.

## Article detail

- The generated Article List screen was used as the visual reference and continued its first article.
- Pushed reading page with `文章详情`, article metadata, blue geometric cover, readable body, practice callout, and safe-area `收藏 / 分享` action row.
- No bottom TabBar.

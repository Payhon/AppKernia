# Decisions

1. 个人中心入口使用危险语义文字链接，位于退出登录按钮下方，保持 44px 点击区且仅登录和功能开启时显示。
2. 页面先解释“当前 App、立即、不可恢复”，再列出删除项和匿名化保留项，避免以模糊的“注销”代替真实后果。
3. 验证邮箱由服务端从当前会话派生；客户端只显示脱敏邮箱，不能提交邮箱或用户 ID。
4. 验证码为六位数字，10 分钟有效、60 秒重发冷却、最多五次尝试；验证码不持久化。
5. 确认勾选默认关闭；验证码完整且勾选后才启用危险按钮，提交前再显示原生不可逆确认弹窗。
6. 成功后先做本地 Push 注销和认证/缓存清理，再重启到登录页；失败时不清理本地会话。
7. 复用 Mobile Master 的系统字体、分组卡片、`status.danger` 和安全区规范，不引入新字体、营销色或 emoji。
8. Auth Context 的 `feature_flags` 按 UTS `Map.forEach(value, key)` 解析；“我的”每次显示时刷新服务端功能快照，瞬时失败保留上一次有效快照。
9. 退出登录与删除账号放入页面视口内的非滚动 `profile-actions`，菜单独立滚动；不以固定高度或额外 spacer 猜测 TabBar 安全距离。
10. HTTP 取消对象区分 `cancelled` 与 `finished`：请求完成即释放原生 `RequestTask`，页面卸载只中止仍在进行的任务，取消后的回调不再触达已卸载页面。

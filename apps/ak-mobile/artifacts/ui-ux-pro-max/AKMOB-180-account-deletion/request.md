# Request

日期：2026-08-30

为 App 上架合规实现当前 App 账号删除闭环：在个人中心退出登录下方增加文字入口，独立页面明确解释立即且不可恢复的影响范围，通过当前已验证邮箱发送六位验证码，并在用户主动确认和二次确认后删除当前 App 的账号资料与关联数据。

固定约束：只删除当前 App；其他 App/管理端共享身份不受影响；法律与安全记录只允许匿名化留存；Android、iOS、HarmonyOS 使用同一 UVue 页面和 AK UI 适配层；`zh-CN`、`en-US` 完整等价。

测试反馈补充：修复“我的”页未显示删除账号入口，以及进入“基本资料”后离开时 `RequestTask.abort()` 访问已销毁实例的问题；需保留当前登录态并在 iPhone 16 Pro 模拟器完成可见性、导航和连续进入/返回回归。

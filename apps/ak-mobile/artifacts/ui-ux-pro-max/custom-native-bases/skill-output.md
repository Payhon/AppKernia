# ui-ux-pro-max output

The required design-system search was run for a professional cross-platform developer foundation and launcher identity. Applied guidance:

- Keep one consistent, original SVG/PNG brand mark; do not use emoji or DCloud default artwork.
- Preserve a clear silhouette at small sizes and use platform-specific safe areas rather than stretching one bitmap blindly.
- Keep the established AppKernia blue as the native identity color and avoid introducing unrelated typography or decorative effects.
- Treat platform icon masks and launch-window crops as part of visual acceptance.

The generic search's landing-page, CTA and web-font suggestions are not applicable to native launcher assets and were intentionally not adopted.

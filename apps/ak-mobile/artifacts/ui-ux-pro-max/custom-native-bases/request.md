# Request

Build AppKernia-branded Android, iOS and HarmonyOS native development artifacts from the repository's existing brand assets. Android and iOS must run only with a custom playground; HarmonyOS must use a local AppKernia native package instead of the generated `io.dcloud.uniappx` identity.

Acceptance includes deterministic icon assets, native identifiers, build entry points, artifact inspection and explicit separation of build, simulator and physical-device evidence.

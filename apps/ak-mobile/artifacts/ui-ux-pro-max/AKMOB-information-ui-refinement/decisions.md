# Decisions

- 图标视觉尺寸从约 24px 收敛为默认 16px，但所有可点击目标保持 44 × 44px；登录、保存、提交、应用筛选和危险操作保留文字按钮。
- 浏览列表按 `article`、`gallery`、`video` 使用三种稳定模板；筛选采用草稿/应用模式，避免每次点选都触发网络刷新。
- 搜索使用全屏透明 DialogPage，从右侧进入；最近搜索仅保存在当前 App 会话，不将潜在敏感查询写入持久化存储。
- `ak-content-viewer` 仅负责类型分派；文章、图文、视频分别由独立查看器渲染受控原生节点。
- 2026-08-28 测试纠正：最初使用 `uni.getVideoInfo` 的方案在缺少可选 `uni-media` 模块的自定义基座中发生 iOS 运行时缺类崩溃，已由 `AKMOB-information-viewer-feedback` 取代。当前使用封面自然宽高作为无原生模块依赖的方向提示，缺失时回退横屏；用户切换后不再被异步封面加载覆盖。
- 四栏图标使用本地原创几何 SVG 确定性生成 81 × 81 PNG，语义分别为首页、指南针浏览、叠层专题和个人资料。

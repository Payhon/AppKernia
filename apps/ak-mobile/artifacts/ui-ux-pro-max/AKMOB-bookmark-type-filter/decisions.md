# Decisions

- 根因修在服务端事实源：客户端已经发送 `type`，OpenAPI 也声明该参数，但收藏 SQL 未应用筛选。
- 收藏查询同时落实契约已声明的 `q`、`type`、`cursor`、`limit`，并按收藏时间稳定分页，避免只修 Tab 而继续留下搜索和分页失效。
- 客户端切换 Tab 时取消活动请求并显示 loading；响应使用请求序号保护，避免快速切换导致较慢的旧响应覆盖新结果。
- 保留既有四个类型和现有视觉样式，仅补 `tablist`/`tab`/`aria-selected` 语义，不新增文案或颜色。
- 增加服务端查询构建单测和 Mobile 跨层静态契约测试；运行环境可用时再以 iOS 自动化和真实 API 数据验证。

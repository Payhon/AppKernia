# UI Skill Output

The repository skill was run for a mobile first-launch consent surface and image-only onboarding carousel. Retained guidance includes a restrained single-surface hierarchy, reachable bottom safe-area actions, 44 px targets, text-independent state, larger-text resilience and explicit accessibility descriptions.

The generic recommendation to offer Skip was rejected because the approved product requirement explicitly forbids it. External fonts, generated artwork and a new palette were also rejected in favor of the packaged App metadata and existing AK tokens.

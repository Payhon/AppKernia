# UI Skill Output

The required search was run with:

```text
mobile app upgrade dialog forced optional update download progress accessible trustworthy
```

The generic result proposed an App Store landing pattern, vibrant blocks, indigo/green colors and downloaded Lexend/Source Sans fonts. Those recommendations conflict with the packaged Mobile design system and were rejected.

Useful retained guidance:

- show explicit progress for long-running work;
- announce errors with text rather than color alone;
- provide accessible names for interactive controls;
- respect reduced motion and maintain readable contrast.

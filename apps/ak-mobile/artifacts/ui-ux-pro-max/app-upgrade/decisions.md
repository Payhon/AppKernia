# Decisions

- Inherit `design-system/MASTER.md`: system fonts, AK blue, grouped white surface, 18–22 px radii and restrained elevation.
- Use a single focused modal card with version transition, bounded release notes, mandatory callout, progress and primary/secondary actions.
- Do not reuse the reference module's raster artwork, hardcoded Chinese text, notification progress or uniCloud flow.
- Keep optional cancel visible; block system/back dismissal for mandatory upgrades.
- Treat Android APK installation, iOS/Harmony store handoff and mandatory return checks as native-device acceptance items.

# Review checklist

- [ ] All visible strings are `AkI18n` keys in both locales.
- [ ] Minimum touch target is 44 px.
- [ ] Authorized, limited, denied, restricted and unavailable states use text plus icon.
- [ ] Loading and errors are visible and recoverable.
- [ ] No permission prompt occurs during bootstrap or page load.
- [ ] Returning from system settings refreshes status.
- [ ] Android, iOS and Harmony adapters use supported native settings routes with fallbacks.
- [ ] Screenshots are captured only from executed builds; unavailable platforms remain explicitly blocked.

# Decisions

1. 根因不是第二个图标组件，而是 `ak-bottom-sheet` 标题栏异常的标签换行产生了独立 `>` 文本节点。该节点成为第三个 flex 子项，显示为无行为箭头并把关闭按钮挤向中间。
2. 将标题栏模板改为规范 UVue 嵌套，删除所有独立尖括号文本节点。
3. 标题设置 `flex: 1`，关闭按钮作为最后一个且唯一的标题栏操作，稳定占据最右侧。
4. 关闭按钮继续使用语义化 `common.close` 标签和至少 44×44px 触控区域；不新增用户可见文案。
5. 公共组件修复同时覆盖登录提示、评论和分享等使用 `ak-bottom-sheet` 的场景。

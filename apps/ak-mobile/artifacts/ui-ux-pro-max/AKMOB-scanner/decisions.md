# Design decisions

1. 扫码按钮放在消息图标右侧，图形 22 px、触控区 44 × 44px，访客也可用；loading/disabled 与协调器 single-flight 共同防止重复拉起。
2. 权限只在用户点击后申请。拒绝浮层提供重试、系统设置和取消；系统扫码界面的主动取消不显示错误。
3. 普通结果用 `ak-bottom-sheet` 展示统一格式与可换行原文，只有明确点击后写剪贴板。
4. 可信网页通过 60 秒一次性内存 Token 进入静态 WebView 页面，不把 URL 放在路由参数，也不开放消息桥。
5. WebView 首次加载和每次导航事件重新校验；越界后关闭并回到原始扫码结果及拦截说明。
6. 处理器注册表优先于网页和结果兜底，给未来 PC 登录与设备绑定保留稳定扩展点。

# Bookmarks page override

遵循 `../MASTER.md` 与 `information-app.md`。

- “全部、文章、图文、视频”是同一收藏集合的互斥类型筛选，选择后必须重新请求对应 `type`，不能仅改变选中样式。
- Tab 使用品牌蓝选中面、`on-brand` 标签和增强字重；同时暴露 `tablist`、`tab` 与 `aria-selected` 语义，不能只依赖颜色表达状态。
- 切换类型时立即进入明确的 loading 状态，并取消上一条列表请求，避免旧响应覆盖新选择。重复点击当前 Tab 不重复请求。
- 每个筛选结果独立呈现 content、empty、offline 或 error；空结果不回退显示“全部”的旧列表。
- Tab 命中区不小于 44 px；横向滚动不得与页面返回手势冲突。
- “我的”页收藏入口暴露本地化按钮名称，自动化和读屏都能按“我的收藏”识别入口，而不依赖坐标点击。
- 收藏结果卡片以文章标题作为按钮的可访问名称；卡片内部的类型、摘要和图片仍保持可视内容，不将一整张卡片读成无名称容器。

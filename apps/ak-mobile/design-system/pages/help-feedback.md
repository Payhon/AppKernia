# Help and feedback

Follow MASTER.md and auth-legal.md. Use compact neutral cells, 16px body text, 44px actions and normal text blocks for CMS content. The local version footer must remain visible without a successful request. Feedback forms scroll above the keyboard; screenshot controls expose progress and localized errors. Never persist feedback drafts or private preview URLs in ordinary storage. Status and replies use text plus semantic colors, with full wrapping in both locales.

## 原生深色复核
UVue 正文和菜单文本显式绑定 `--ak-text`，不能依赖 view 颜色继承。共享返回控件保留 20px SVG/44px 触控区，深色时使用浅色描边；反馈列表行提供问题描述的可访问名称。

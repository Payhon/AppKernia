# Home override

- Header starts below the status-bar safe area and contains the product mark plus a 44 px notification affordance.
- The greeting uses a large-title hierarchy but stays subordinate to system chrome. Supporting copy uses secondary label color.
- A single blue hero establishes the primary action with explicit high-contrast label text. Follow with a two-column grid for Articles, Messages, Security and Settings.
- Quick cards use 12 px horizontal and vertical separation, a quiet tinted icon well and a full-card tap target. They must never touch at the center seam.
- Featured articles are short horizontal cards; secondary query failure never hides profile and quick actions. Error/retry content remains above the TabBar.

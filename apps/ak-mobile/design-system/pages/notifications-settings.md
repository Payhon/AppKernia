# Notifications, Settings and Security override

- Root notifications use a safe-area large title and inset-grouped message cards. Unread state uses weight plus a leading indicator, never color alone.
- Settings and security pages use an iOS-style inset-grouped list structure: section spacing, 44 px minimum rows, semantic leading icon wells and secondary values.
- Device/session rows place destructive actions below or in a trailing compact control without squeezing the device name and metadata.
- Form pages group fields in a surface and keep the primary action reachable above the bottom safe area and keyboard.
- Empty/error states remain vertically balanced in the available flex area and keep the retry action visible.

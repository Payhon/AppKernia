Applicable findings:

- Announce loading, success, validation, and error feedback to assistive technology.
- Keep all mode and form actions keyboard reachable with visible focus.
- Use controlled React fields for the dynamic settings form.
- Use semantic buttons/controls and text labels rather than icon-only switching.
- Verify contrast, reduced motion, and responsive layouts at 375, 768, 1024, and 1440 px.

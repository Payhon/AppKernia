# AKADM System Config Form Mode Request

Add a form-first view to System > System Settings > System Configuration. Keep the existing table as the configuration-definition workspace, add a top mode switch, render current definitions as direct typed fields, and save all changed values with one action. Form mode must be the default.

Required runtime coverage: zh-CN and en-US, keyboard/focus, 375/768/1024/1440 widths, dirty-change protection, partial-save feedback, and no secret value disclosure.

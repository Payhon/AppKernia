# AKADM-010 Design Decisions

1. 采用统一企业蓝 `#1E40AF`，主动作使用蓝色；琥珀色仅用于告警/注意，不作为常规主按钮。
2. 使用系统 sans/monospace 字体栈，避免运行时依赖 Google Fonts，减少隐私、离线和首屏性能风险。
3. 不使用 hover 位移或缩放；只改变颜色、边框和阴影，避免布局抖动。
4. Ant Design light/dark algorithm 共享语义 token；暗色不是简单反色。
5. 登录采用安全控制台的双栏信息架构，窄屏折叠为单栏；不使用营销落地页区块。
6. App Shell 使用固定侧栏、可折叠窄屏抽屉、顶部工作区与语言入口；后端菜单只控制可见性，静态 route registry 决定可执行组件。
7. 所有 icon 使用同一套内联 SVG 轮廓风格，并提供可访问名称；不使用 emoji。
8. 所有动态状态提供文本反馈；图表必须有表格或文本替代。

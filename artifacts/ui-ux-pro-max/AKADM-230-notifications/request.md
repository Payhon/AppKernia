# AKADM-230 UI Skill Request

Design the authenticated AppKernia Admin notification center for announcements, in-app messages, localized templates, and delivery records. The UI must support recipient selection with an exact audience preview and explicit publish confirmation, safe plain/Markdown/HTML preview, template-variable validation, failed-delivery detail and retry confirmation, bilingual zh-CN/en-US content, keyboard access, and responsive layouts from 375 to 1440 pixels.

# AKADM-130 Access Control Decisions

- 保持既有 Navy/Blue、系统字体与 App Shell；采用数据密集但分区清晰的后台结构。
- 角色列表使用隐藏详情路由；详情以基本、权限、菜单、数据范围、成员五个标签组织，权限树与菜单树绝不合并。
- 权限目录只读，按 module/resource 分组并提供复制稳定权限码；前端不允许新增后端权限。
- 菜单使用树表和 Drawer；`component_key` 是静态 Registry Select，不接受任意组件路径。
- 移动菜单同时支持键盘可操作的父级 Select 与排序字段；服务端校验最大三级和循环，拖拽不作为唯一交互。
- 角色删除、权限/菜单替换和数据范围变更展示影响并确认；系统角色的不可变边界由服务端强制。
- 375px 收敛非核心列；筛选与分页写入 URL，双语均验证长文案布局。

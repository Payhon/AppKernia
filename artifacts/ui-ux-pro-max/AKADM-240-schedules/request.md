# AKADM-240 UI Skill Request

Design the authenticated AppKernia Admin scheduled-jobs workspace for compile-time handlers, Cron expressions, IANA time zones and DST-aware next-run previews. The UI must support URL-restored filters, create/edit drawers, pause/resume, confirmed manual execution, run history, bilingual `zh-CN`/`en-US` content, keyboard access, reduced motion and responsive layouts at 375, 768, 1024 and 1440 pixels.

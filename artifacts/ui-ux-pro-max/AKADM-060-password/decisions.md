# Decisions

- 使用 `current-password` 与 `new-password` autocomplete，兼容密码管理器。
- 使用 Ant Design `Input.Password` 提供键盘可达的显示/隐藏控件。
- 表单本身要求当前密码、新密码和二次确认，已经构成明确的高意图动作；页面提前说明会撤销其他会话，不再叠加第三个确认弹窗。
- 客户端只用稳定错误码区分“当前密码错误”“历史复用”和通用失败，不显示服务端英文原文。
- 密码写请求不走自动 refresh/replay；当前会话保留，其他会话由后端事务撤销。
- E2E 只验证错误态以避免改变固定验收账号；成功修改、历史复用、旧/新登录与会话撤销由 PostgreSQL 集成测试使用临时账号覆盖。

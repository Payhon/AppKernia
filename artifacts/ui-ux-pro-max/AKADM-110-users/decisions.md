# AKADM-110 User Management Decisions

- 采用现有 Navy/Blue、系统字体和 App Shell；拒绝营销 Hero、外部字体、3D/视差、暗色强制主题和琥珀主 CTA。
- 1200px 及以上使用部门树 + 数据表；更窄视口隐藏部门树并让 1050px 操作表格在受控容器内横向滚动；详情使用隐藏路由，轻编辑使用 Drawer。
- 小于 768px 时不把固定操作列覆盖在用户信息之上：隐藏次要列，把状态并入用户主列，把多按钮收敛为权限过滤后的动作菜单。
- URL 恢复筛选、分页和排序；批量选择变化用 live region 公告。
- 角色/部门/岗位引用均由后端按当前租户重新校验；前端权限只控制体验。
- 导入返回逐行稳定错误码摘要；导出遵循服务端筛选与字段白名单，不导出 Secret/Hash。
- 所有写请求禁用自动 replay，破坏性动作说明会话/访问影响并允许取消。
